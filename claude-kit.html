01

시작하기 A–Z

세 단계면 끝납니다. 검은 창은 Windows Terminal(PowerShell) 화면입니다. PS C:\…> 줄은 프롬프트에서 치는 명령, > 줄은 Claude 안에서 치는 말, ⏺는 Claude의 답이나 도구 실행입니다. 유료 플랜(Pro · Max · Team) 계정이 필요합니다.

A

설치와 확인

터미널에 한 줄 붙여넣고 버전이 찍히면 끝. 이후 업데이트는 자동입니다. 문제가 있으면 claude doctor.

B

로그인 · 첫 실행 · 프로젝트 설정

작업 폴더에서 claude를 실행하면 처음 한 번 브라우저 로그인이 열립니다. /init은 Claude가 매번 읽는 메모(CLAUDE.md)를 만듭니다.

C

플러그인 · MCP · 스킬 붙이기

플러그인은 /plugin install 이름@claude-plugins-official, MCP는 셸에서 claude mcp add, 스킬은 npx skills add. MCP는 3~6개 이내로.

D

에디터에서 쓰기

VS Code · Cursor는 확장 보기(Ctrl+Shift+X)에서 "Claude Code" 설치, JetBrains는 플러그인 마켓에서 같은 이름. 터미널이 낯설면 데스크톱 앱(claude.com/download).

03

활용 예시

실제 대화 흐름 네 가지. 이렇게 말하면 됩니다.

1

요구사항 확정 → 스펙 → 티켓

/grill-me가 질문으로 범위를 좁히고, /to-spec · /to-tickets가 문서와 티켓으로 만듭니다. 모두 mattpocock-skills.

2

디자인 → 코드

Figma 링크(node-id 포함)를 붙여넣기만 하면 Figma MCP가 읽습니다.

3

화면 검증

agent-browser가 브라우저를 직접 열어 확인하고, web-design-guidelines가 접근성을 검토합니다.

4

문서 업무와 마무리

문서 스킬 · humanizer는 설치만 해 두면 자동으로 동작합니다. 커밋은 말로 하면 됩니다.

팁. 큰 작업은 Shift+Tab으로 Plan 모드에 두고 계획을 먼저 받으세요. 길어지면 /context로 확인하고 다른 일을 시작할 때 /clear. 요청은 "로그인 버그 고쳐줘"보다 "잘못된 비밀번호 입력 시 빈 화면이 뜨는 로그인 버그 고쳐줘"처럼 구체적으로.
